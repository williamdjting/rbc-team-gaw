Experiments 01–07 + CEMS extensions · Consolidated overview

Can learned models improve on hotspot persistence?

Objective: predict whether a hotspot detection will be recorded in an H3 cell on the next day, and test the added value of neighbour features and graph message passing.

Dataset and class balance

  • Data: FIRMS VIIRS S-NPP observations, fixed resolution-7 H3 grids; May–September 2018–2023. Target dates start May 8 to allow seven days of history.
  • Scope: Experiment 01 is a single-region pilot; The BC experiments use six BC Fire Centres and 234,554 region-specific grid nodes.
  • Target: 1 = at least one detection recorded on the target day; 0 = no detection recorded. Coverage remains unknown; these are not ignition or verified fire-absence labels.

Experiments and methodology

ExperimentMethodOne-line purpose
01 · Persistence pilotFixed count-based rules using 1-, 3- and 7-day local/neighbour histories in one region.Quantify whether recent observed activity recurs the next day.
02 · BC persistenceRepeat the rules independently across all six regions.Establish a wider regional benchmark.
03 · Learned baselinesPooled logistic regression and gradient boosting, each with cell-only and neighbour-enhanced inputs.Test whether learning feature combinations improves the fixed-rule benchmark.
04 · GNN + MLPTwo GraphSAGE-style mean-aggregation layers; MLP comparison without message passing.Test the contribution of learned graph-based neighbour information.
03a · Baselines + CEMSLogistic regression and boosting with four preceding-day CEMS fire-weather indices.Measure the added value of weather. Available numeric summary: boosting with neighbours.
04a · GNN + MLP + CEMSGraph and non-graph neural models with the same four weather indices.Compare weather-enhanced graph and MLP models.
05 · Full-data CatBoostAll training rows; unweighted and Balanced class-weight variants, with and without neighbours.Test boosting without quiet-negative undersampling or odds correction.
06 · Sampled CatBoostKeep positives and active rows, sample approximately 1% of quiet negatives; correct quiet-row odds by ×0.01.Compare CatBoost under the earlier tabular sampling design.
07 · TabPFN hybridTabPFN on active rows using three 10,000-row training-context draws; sampled CatBoost on quiet rows.Test a foundation-model hybrid with cell-only and neighbour features.

Split: train 2018–2021 → select on 2022 → evaluate on 2023. Persistence selects rules; learned models select per-region thresholds; neural models also select the epoch on 2022.

Features use only earlier dates. CEMS extensions add weather indices from the preceding day. This is a chronological split, not cross-validation. 2023 is development evaluation, not an untouched final test.
