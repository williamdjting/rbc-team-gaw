What the model uses

3Feature importance by input group

  • CatBoost built-in importance: how much the prediction changes when an input changes
  • Measured on training data (2018–2021), scaled to total 100%
  • Summed by input group (e.g. fire history = 28 inputs); click a group to see its inputs
Fire informationOther
  • 62% comes from fire information (history, BCWS incidents, NOAA-20, spread); 36% from weather
  • Top single input: temperature (16.7%)
  • Fire history is led by no fire nearby recently (8.6%), distance to yesterday's nearest fire (6.2%) and days since the last detection (4.2%)
  • Distance to an active BCWS wildfire adds 6.6%
  • Lightning (2.0%) and upwind spread (0.6%) add little
  • The paper's model has no fire-history inputs

Conclusion

What this means for end users

  • Sampling doesn't improve the model; it changes the yardstick. Same model, same ranking in both evaluations
  • Realistic (full map): next-day F1 0.61; a daily watch list of 350 cells per Fire Centre catches 18% of new fires
  • Paper-style (sampled): F1 0.85 and 78% of new fires caught, but only by flagging 28% of BC; just 0.35% of those flags are real new fires
  • Use full-map numbers for operational decisions; use sampled numbers only to compare with published work
